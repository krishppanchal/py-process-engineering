# py-process-engineering

an ongoing portfolio connecting hands-on lab work to industrial chemical engineering, focused on oil & gas and refinery operations. all experimental data were collected by me in a UT Austin lab.

for each experiment, I model the lab data in python from first principles, compare it to measured results, and scale it up to the industrial process it represents.

## projects

| project | what it covers | industrial link | status |
|---|---|---|---|
| [distillation + gc](separations/distillation) | simple distillation of acetone/toluene, gc composition analysis, raoult's law t-x-y model, rayleigh equation | crude oil fractionation | ✅ complete |
| [extraction + recrystallization](separations/purification) | mass balance across a two-step purification process, actual vs. theoretical recovery | solvent extraction, crystallization | 🔜 in progress |
| column chromatography | adsorptive separation | molecular sieves, adsorption units | 🔜 planned |

## tools
python · numpy · pandas · scipy · matplotlib · jupyter

## run it
pip install -r requirements.txt, then open any project's analysis.ipynb
